# Project badges

The Update project badges workflow refreshes release versions, stars, and release-asset download counts daily at 18:00 UTC. Run it manually from Actions after a release to refresh immediately. It uses the built-in GitHub Actions token to commit only to this repository; no personal access token is needed.

The canonical updater is `scripts/update-project-badges.sh`. The local `project2/update-project-badges.sh` entry point pulls this repository and invokes the same script.

Download counts sum downloads of assets attached to all releases. GitHub does not expose downloads of autogenerated source archives or installer scripts through this count. Older badges used accumulated repository clones; those figures are not added to release download counts. Projects without release assets correctly show zero.

If the badge job fails, inspect its Actions log. API failures stop the update rather than saving invalid data. A clean checkout is required for local runs. Concurrent Actions runs are serialized, and unchanged data creates no commit.
